AgentQuest Board is a hackathon project for the Binance Agent ID Hackathon. Contract: not deployed yet (BNB Chain, chain 56).

How it works: connect with an injected wallet (MetaMask / Binance Wallet extension) — no QR login, no WalletConnect. Every action is a transaction you confirm yourself. All quests are free; only network gas applies. The contract holds no funds.

Badges are ERC-1155 tokens with fully on-chain SVG metadata. Max 1 of each badge per wallet.
